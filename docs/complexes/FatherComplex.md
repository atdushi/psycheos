# Комплекс Отца

В нашей ООП-архитектуре Комплекс Отца (Father Complex) выполняет роль Валидатора / Цензора (Code Reviewer). Он отвечает за социальные нормы, авторитеты, правила и закон. В негативном состоянии он выбрасывает синдром самозванца и блокирует амбиции Эго (например, при попытке попросить прибавку к зарплате).
